Tentang Saya

Mengenal lebih dekat

Saya lulusan Teknik Informatika Institut Teknologi PLN dengan IPK 3.76, berpengalaman dalam manajemen proyek IT di berbagai perusahaan. Keahlian saya mencakup pengelolaan proyek end-to-end, kepemimpinan tim, dan problem-solving di lingkungan kerja yang kompleks.

Saya berpengalaman dalam Project Management dengan SDLC maupun Agile, serta menyusun Product Requirement Document (PRD). Sebagai IT Project Manager di Kementerian Keuangan, saya menyelesaikan proyek 1 minggu lebih cepat dari jadwal melalui optimalisasi timeline dan sumber daya.

Saya pernah menjadi Intern Product Manager di PT Vidio Dot Com dan terlibat mengembangkan fitur Sport Widget yang meningkatkan engagement pengguna. Saya juga menjadi team leader di Bangkit Academy oleh Google, Tokopedia, dan Traveloka, tempat saya mengembangkan aplikasi voting Android bernama VOTEXY.

Keahlian teknis saya meliputi Kotlin, Python, UX Design (Figma), serta pengelolaan proyek berbasis Agile dan Scrum. Saya memiliki sertifikasi Microsoft Azure AI Fundamentals dan Microsoft Office Specialist PowerPoint.

Saya berkomitmen terus berkembang di bidang Project Management dan Product Development, serta menghadirkan solusi inovatif yang berdampak bagi perusahaan dan pengguna.

Project

Project Terbaru

Berikut sebagian project yang saya pimpin dan buat.

IT Project Manager 01

Pengembangan Website KNEKS - Kemenkeu RI

Saya memimpin pengembangan website KNEKS (Komite Nasional Ekonomi dan Keuangan Syariah) untuk meningkatkan aksesibilitas dan kualitas informasi bagi pengguna. Sebagai IT Project Manager, saya mengoordinasikan tim dalam memperbarui desain, mengoptimalkan performa, dan menyusun konten yang lebih interaktif. Salah satu inovasinya adalah penerapan algoritma K-Nearest Neighbor (K-NN) untuk klasifikasi kematangan buah, yang membantu menyediakan data berbasis teknologi dalam evaluasi kehalalan produk agrikultur.

Product Management 02

Pengembangan Fitur Sport Widget - Vidio

Saya mengembangkan Sport Widget di aplikasi Vidio sebagai Product Manager. Widget ini menampilkan statistik pertandingan olahraga secara real-time, termasuk NBA dan EPL, sehingga pengguna dapat melihat data pertandingan langsung tanpa membuka halaman detail. Fitur ini meningkatkan engagement pengguna secara signifikan dan membuat Vidio lebih interaktif bagi para penggemar olahraga.

Android · Kotlin 03

Aplikasi Star Story

Aplikasi posting story seperti Instagram yang saya buat dengan Kotlin dan Android Studio. Aplikasi ini sudah mendukung kamera, peta, paging, dan database. Untuk detail project, silakan kunjungi akun GitHub saya.

Android · ML & Cloud 04

VOTEXY (E-Voting)

Aplikasi pemilihan suara elektronik berbasis mobile. Saya membuatnya bersama teman-teman dari learning path Machine Learning dan Cloud Computing. Database tersimpan di cloud, dan aplikasi menerapkan model face recognition: pengguna harus memverifikasi wajah sebelum memberikan suara. Dibuat dengan Kotlin di Android Studio, Java, dan teknologi lainnya. Detail lengkapnya ada di akun GitHub saya.

UX Design 05

GENZETY

Project UX Design untuk aplikasi GENZETY, yaitu aplikasi koneksi mutual yang saya rancang agar peserta Bangkit Academy mudah menjalin relasi. Detail lengkapnya ada di akun GitHub saya.

Jetpack Compose 06

Basket-Store

Aplikasi e-commerce yang berfokus pada penjualan peralatan bola basket, terinspirasi dari Tokopedia. Dibuat dengan Jetpack Compose di Android Studio. Detail lengkapnya ada di akun GitHub saya.

Android 07

GitHub User App

Aplikasi untuk menampilkan pengguna GitHub. Pengguna dapat melihat user favorit dan menambahkan user ke daftar favorit. Dibuat dengan Android Studio. Detail lengkapnya ada di akun GitHub saya.

UI/UX Design 08

UnmuteApp

Prototipe aplikasi yang saya rancang bersama tim untuk mengikuti lomba UI/UX Design. UnmuteApp adalah aplikasi bahasa isyarat tempat pengguna belajar berkomunikasi dengan teman tuli dan sebaliknya. File dan tautan prototipenya ada di akun GitHub saya.

Android 09

Habit App

Aplikasi pengingat jadwal kebiasaan. Pengguna dapat menambahkan kegiatan harian, lalu aplikasi mengirim notifikasi saat jadwal sudah dekat (pengguna perlu memberi izin notifikasi terlebih dahulu). Detail lengkapnya ada di akun GitHub saya.

Android · Kotlin 10

Sojourn.com

Aplikasi pemesanan tiket online berbasis mobile untuk pesawat, kapal laut, dan kereta, dibuat dengan Kotlin di Android Studio. Project ini belum sempurna dan masih perlu banyak perbaikan. Detail lengkapnya ada di akun GitHub saya.
